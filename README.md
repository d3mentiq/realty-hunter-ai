# Realty Hunter AI

Вайбкод проект для автоматического поиска и отбора квартир в аренду. Написан в связке с нейросетями под реальную задачу: быстро мониторить свежие объявления на трех площадках, отсекать мусор и присылать нормальные варианты в телеграм.

## Что умеет проект

- Собирает объявления с Циан, Авито и Яндекс Недвижимости через тихие запросы.
- Отсекает неподходящие этажи, скрытые платежи, комнаты, подселения и запрещенные ключевые слова.
- Считает реальный первый взнос с учетом разбивки залога и комиссии риелтора.
- Оценивает ремонт и технику по фотографиям через зрение нейросети, если указан API ключ.
- Сохраняет все находки в локальную базу SQLite с поддержкой параллельной записи.
- Дает удобный телеграм бот для модерации: кнопки отбора, ручные оценки от 1 до 10, личные заметки и просмотр по категориям.

## Быстрый старт

### 1. Установка зависимостей

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/d3mentiq/realty-hunter-ai.git
cd realty-hunter-ai

python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
.\venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

### 2. Настройка окружения

Скопируйте файл с примером настроек:

```bash
cp .env.example .env
```

Откройте `.env` и впишите свои параметры:
- `TELEGRAM_BOT_TOKEN`: токен вашего бота от BotFather.
- `ALLOWED_USER_IDS`: ваш числовой ID в телеграме через запятую.
- `CITY`: название города для поиска.
- `MIN_PRICE` и `MAX_PRICE`: диапазон цен аренды в рублях.
- `DISALLOWED_FLOORS`: нежелательные этажи (например, 1).
- `GEMINI_API_KEY`: ключ к API для оценки фото (необязательно, можно оставить пустым).

### 3. Проверка и первый запуск

Запустите быстрый тест логики и базы:

```bash
python test_smoke.py
```

Запустите разовый сбор и фильтрацию объявлений:

```bash
python hunter.py --once
```

Чтобы запустить бота для разбора квартир:

```bash
python telegram_bot.py
```

Чтобы запустить фоновый воркер постоянного мониторинга:

```bash
python hunter_worker.py
```

## Особенности работы

- Сеть: запросы идут через curl-cffi. На датацентровых IP зарубежных серверов Авито и Циан могут отдавать 403. С домашнего подключения или резидентских прокси всё работает ровно.
- Доступ: бот отвечает только пользователям из `ALLOWED_USER_IDS`. Если список не задан, доступ закрыт для всех.

## Структура кода

- `config.py`: загрузка параметров из окружения с привязкой базы к корню проекта.
- `hunter.py`: главный пайплайн сбора, фильтрации и отправки уведомлений.
- `hunter_worker.py`: фоновый процесс с периодическим запуском поиска.
- `regex_engine.py`: правила отсева текста, расчет залога, комиссии и коммуналки.
- `vision_judge.py`: оценка состояния ремонта и бытовой техники по фото.
- `tracker_db.py`: хранилище объявлений, статусов и заметок на базе SQLite в режиме WAL.
- `telegram_bot.py`: бот с кнопками модерации, сменой категорий и оценками.
- `scrapers/`: модули сбора данных для Циан, Авито и Яндекс Недвижимости.
- `test_smoke.py`: базовый смоук-тест базы и текстового фильтра.
